# HotelReservationSystem

## Project Description
The Hotel Reservation System is a Java-based application developed to manage hotel room reservations.

This project allows users to view available rooms, make reservations, and manage booking details.

## Features
- View available hotel rooms
- Book a hotel room
- Enter customer details
- Display reservation information
- Manage room reservation details

## Technologies Used
- Java
- Object-Oriented Programming
- VS Code

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Compile the Java files.
4. Run the main Java class.
